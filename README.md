# PaperJoy 纸趣儿童打印素材

## 运行原则

本地电脑下载、整理、排版并检查打印文件；网盘保存和分发 PDF/ZIP；服务器保存资源目录、压缩预览图、链接和领取记录。按前期讨论的 2 核 2G 约束设计，部署前核查实际资源及已有服务。

账号密钥和数据库密码通过部署环境配置，不存入公开仓库。源码复用前检查原项目许可与用户自有代码边界，使用独立数据库、应用标识和后台配置。
