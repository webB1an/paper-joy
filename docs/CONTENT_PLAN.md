# PaperJoy 素材生产与授权方案

## 首批目标

先完成动物涂色、分级迷宫、控笔与奖励表三个主题包。首批目标合计约 40—60 页活动内容，迷宫另附答案。当前下载的 SVG 仅是来源素材，不是已排版、可发布的成品包。

| 类型 | 主要生产方式 | 检查重点 |
|---|---|---|
| 动物/植物涂色 | 逐件许可明确的线稿，必要时原创补充 | 线条清晰、留白、题材适龄、授权来源 |
| 迷宫 | 本地程序生成 | 有解、起终点、答案一致、难度与尺寸 |
| 控笔 | 本地程序排版 | 线宽、间距、打印边距、形状与练习量 |
| 奖励表 | 自有版式 | 中文字体、书写空间、使用说明 |

## 下载与许可记录

本轮先下载 Openclipart 的普通兔子与花卉线稿样本。作品文件及清单放在 `assets/source-materials/`。记录作品页、原作者、下载 URL、获取日期、文件哈希、许可依据和处理状态。

[Openclipart 官方 FAQ](https://openclipart.org/faq)声明采用 CC0 并允许商业使用和修改；仍须检查具体作品的来源和疑似侵权标记。排除 `pd_issue`、`need-review`、知名角色、商标和来源不清的作品。保存网页证据用于追溯，不把站点声明理解成对每件作品的无限保证。

Supercoloring 仅在具体作品许可明确时逐件纳入，本轮获取的熊猫页文本没有直接展示完整许可信息，因此不依据上一次聊天的判断自动入库。Abby the Pup 之前有授权说明相互不一致的问题，未进一步核实前不用于首批商业分发。

不通过搬运付费资料、去水印或把「可商用成品」误当成「可重新分发源文件」来扩库。购买或委托素材时需要明确允许 PDF 编排、小程序展示、网盘分发和广告获益。

## 目录与流程

`assets/source-materials/` 保存少量可追溯基础素材；批量原始文件、私有授权合同与生成的 PDF/ZIP 放在 Git 忽略的工作目录，生产库维护相应索引。只有准备在仓库公开的来源样本和说明进入 Git。

每个成品包应包含 PDF、清晰文件名、页数说明、打印指南；有题目的包附独立答案。优先 A4 黑白，四周保留打印安全边距，字号和线宽经过试印。需要字体时选择许可适合嵌入和分发的字体，并附对应许可说明。

## 发布门槛

每包完成文件打开、页序、尺寸、内容逻辑、预览匹配、来源台账和网盘链接检查；先发布少量经过试印的内容，再扩大数量。自动验证无法替代实际打印，现阶段不把来源素材数量当作可售或可领取成品数量。
