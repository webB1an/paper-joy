# 首版实施记录

2026-11-06。

## 已实现

- npm workspaces、Node 22、锁文件、GitHub CI、独立 build/src。
- 原生小程序四入口及搜索、专题、详情、领取、反馈、协议页面；液态玻璃导航与实底降级；最新蜡笔 Logo。
- 游客浏览领取、本机收藏记录；可选微信登录、服务端 JWT、带离线待同步队列的收藏合并；不采集头像手机号。
- 公开详情与稳定 ID、分享配置；打印属性、来源许可、预览；百度/夸克链接复制和失效反馈。
- 运营后台登录、资源编辑、分类专题、预览上传、来源、导入去重、上下架、网盘账号、同步任务、反馈和基础统计。
- 真实 MySQL schema/migration；发布前验证预览文件、来源、打印字段与网盘链接；任务唯一活动锁和单任务执行。
- 双盘检查点与失败恢复、成功结果不重复发放；两盘成功后才清理源 PDF。
- 广告开关、结束/取消/失败/离页及重复事件处理。客户端完成事件不是可靠的服务端广告观看证明。
- 12页涂色、20页迷宫＋20页答案、12页控笔奖励表，本地 A4/PDF/预览/哈希与来源记录。

## 验证口径

类型检查、构建、API 与小程序单元测试；独立测试 MySQL 的真实 API 集成；迷宫连通性及答案校验；PDF 页数/A4/嵌入字体与接触表逐页视觉检查；管理后台浏览器验收。详细部署验证随体验发布更新。

没有 AppSecret、网盘授权和广告位时，微信账号登录、真实双盘上传与激励广告尚不能完成端到端联调。初始素材保持待检查，真实打印与真机体验由用户补验。后台浏览器与模拟测试不等于微信真机验收。
