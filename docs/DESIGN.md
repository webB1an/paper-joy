# PaperJoy 液态玻璃视觉方案

## 品牌方向

「纸趣」体现纸上活动，「儿童打印素材」说明用途。当前 Logo 使用开放式蜡笔与笑弧，满幅蓝底；不使用封闭容器、边框或折角。应用使用 v5 的 144×144 PNG，后续可替换品牌资产重新构建。

图标文件位于 `assets/brand/`，生成提示词与内置图像工具记录见该目录的 README。

## 材质分工

液态玻璃用于浮动底部导航、筛选胶囊、领取按钮容器和必要的浮层。素材内容卡片用安静的暖白底，打印稿内页保持纯白、黑线，避免透明材质影响用户判断文件质量。

这一分工参考 [Apple 材质指南](https://developer.apple.com/design/human-interface-guidelines/materials)：Liquid Glass 主要承担控件与导航层。微信小程序采用相近视觉表达；苹果系统原生材质接口不直接适用于小程序。

## 设计参数

| 项目 | 初稿参数 |
|---|---|
| 页面底色 | `#F8F6F2` |
| 正文 | `#252733`，次级文字 `#666975` |
| 主操作色 | `#356ADE`，白色按钮文案 |
| 装饰色 | 珊瑚 `#FF947D`、天蓝 `#8BD6F2`，不直接承担小字号正文 |
| 玻璃容器 | 高透明度白色填充、细浅边、高光和轻阴影 |
| 圆角 | 内容卡片约 20px，胶囊与浮动导航按结构取值 |
| 交互 | 短时淡入和位移，减少连续背景动画 |

实际字号、色彩对比和点击区域以真机验收为准。导航避让微信胶囊和底部安全区；长标题、弱网、空态、加载态、失效链接都需要独立设计。

## 性能与降级

优先使用简单层次表达玻璃感。背景模糊只作用于有限面积，避免列表每张卡片都应用模糊；不为折射效果引入整页实时图像渲染。微信渲染引擎、基础库和系统版本差异需要验证，不假定所有设备支持同一 CSS 效果。

不支持或性能不足时降级为浅色实底、边框和阴影；降级后信息与操作保持一致。打印预览使用压缩图片、分页/懒加载，小程序不加载整包 PDF 来展示列表。

## 页面重点

首页突出搜索与三个核心主题；列表显示资源真实封面和页数；详情优先回答「是什么、适合谁、准备什么、怎么打印」；领取页明确百度/夸克去向、提取码和操作步骤。图标、空状态和专题封面保持同一颜色与线条体系。
