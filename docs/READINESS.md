## 用户需补齐的内容

| 内容 | 何时需要 | 提供方式 |
|---|---|---|
| 小程序 AppID、最终名称 | 导入微信开发者工具与真机联调前 | 注册后提供 AppID；名称暂按「纸趣儿童打印素材」 |
| AppSecret | 微信登录接口联调前 | 填写本地私有配置或服务器环境变量，不提交 Git |
| 小程序主体、类目、认证/备案状态 | 公开上线和能力开通前 | 在微信后台完成并核对当前要求 |
| 子域名备案归属 | HTTPS 和小程序请求联调前 | A 记录已核对指向目标服务器，仍需确认父域名备案与主体适配 |
| 百度与夸克上传/分享授权 | 真实文件上架前 | 在管理界面授权或使用可访问的本地配置；先确认是否使用现有推广账号 |
| 广告能力与广告位 ID | 广告联调前 | 新小程序后台开通后配置，旧项目广告位不直接复用 |
| 客服或反馈联系方式 | 上线前 | 提供用于用户反馈与隐私说明的联系渠道 |
| 少量试印反馈 | 首批包发布前 | 用真实打印机检查裁切、线条、页序和儿童活动难度 |

暂无 AppID 可以先开发演示页面和后台，但无法代替真实微信登录、广告和审核联调。暂无广告资格可先上线免费版本，相关入口通过配置关闭。

## 开发方处理

Logo、配色与组件规范；小程序、API 和后台；原项目可复用能力整理；来源明确的素材下载、来源台账、排版与本地生成脚本；数据库建表和迁移；域名证书与反向代理；日志、备份和恢复；隐私政策与用户协议草稿；Git 提交与推送。

上线前核对服务器系统、已有站点、可用内存、MySQL 和端口；避免安装或重启时影响既有产品。数据库用户限制到本项目数据库和本机访问，不开放公网数据库端口。使用独立服务名与路径，准备可回退的版本。

## 网络检查状态

2026-11-05 使用 Google 公共 DNS over HTTPS 复核，`paper-joy.wdbzk.com` 的 A 记录为用户指定的目标服务器地址。当前机器自身查询经过代理返回 `198.18.*.*`，本次公网判断以公共 DNS 回答为依据。HTTPS 证书、站点配置和备案状态仍待核对。

自建服务的小程序网络请求需要 HTTPS 和配置合法域名，公网 IP 不能直接替代该域名；微信文档还要求域名经过 ICP 备案。参见[微信网络能力文档](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/network.html)。证书配置完成不等于小程序备案与后台域名配置同时完成。
